# 路径迁移的三种写法

> **一句话**：Windows 路径有三种写法，批量替换漏一个就漏一片。

## 问题

把目录从 `D:\old` 迁到 `D:\new\moved`，写脚本批量替换路径引用，结果验证时还残留 38 个文件。

## 根因

同一个路径在脚本 / 文档里有三种写法，只替换了一种：
1. `D:\x`（反斜杠，Windows 原生）
2. `D:/x`（正斜杠，跨平台 / Markdown）
3. `/d/x`（MSYS / Git Bash）

## 解法

三种写法都替换，且边界字符要含 Markdown 反引号、中文右引号、英文逗号、英文句号。

## 反直觉判断（真正踩坑点）

1. 路径不是「一个字符串」，是「三种写法」
2. Markdown 内联代码 `` `D:\x` `` 的反引号是边界字符，漏了会漏改
3. 启动项（.vbs/.lnk）是文本替换盲区，要单独查

## 通用迁移

> 批量替换前，先枚举「同一个目标」的所有写法变体 + 所有引用位置，再动手。
