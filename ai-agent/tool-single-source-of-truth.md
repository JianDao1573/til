# 工具别复制到处改

> **一句话**：工具是单一真相源，改动必须反哺回源。

## 问题

工具代码被复制到多个项目里用，各处副本慢慢分叉——改了一处，另一处还是旧的，工具慢慢退化。

## 根因

「复制」让工具有了多个「真相源」，改动无法同步。

## 解法

工具类项目 = **单一真相源**：
- 源在 `D:\projects\<tool>\`
- 其他项目可 **copy 引用**（复制过去用）
- 但**改动 / 升级必须回源项目改**，禁止在 copy 处直接改
- 改完源再 copy 出去覆盖各引用处

## 反直觉判断（真正踩坑点）

1. 「copy 引用」和「改动反哺」是配套的，只 copy 不反哺必分叉
2. 单一真相源 ≠ 不能复制，而是「复制可以，改动只在一处」
3. 工具和 skill 要同名对应，改名要联动（先调研引用）

## 通用迁移

> 可复用资产只存一处，其余引用；改动回到源头，再同步出去。
