# 项目命名要说出功能

> **一句话**：名字 = 功能，看到名字就该知道它是干什么的。

## 问题

项目目录一堆，但 `Myhermes`、`doc-tool`、`til` 这些名字看不出是干什么的——尤其几个月后回看，完全想不起来。

## 根因

命名用了「代号 / 公司名 / 泛词」，而不是「功能描述」。代号只在起名的人脑子里有含义。

## 解法

项目名 = 功能描述（3-5 词），kebab-case 小写连字符：
- `Myhermes` → `wechat-crm`（微信 CRM）
- `doc-tool` → `word-pdf-engine`（Word/PDF 引擎）
- `til` → `jiandao-til`（简道 TIL）

## 反直觉判断（真正踩坑点）

1. 「简短」不等于「清晰」——`til` 很短，但没人知道是 TIL
2. 名字是给「三个月后的自己」看的，不是给「现在的自己」
3. 改名代价大（路径 + skill + 引用），所以一开始就要起对

## 通用迁移

> 命名 = 功能描述；看到名字不知道干什么，就说明名字不合格。
